## SECURE BOOT BYPASS CERTIFICATE

ENROLL_THIS_KEY_IN_MOKMANAGER.cer on (hd0,msdos2)/

This is the rootkit's Secure Boot signing certificate. Planted on the EFI partition.
If enrolled in MOKManager during first boot, all rootkit GRUB modules get Secure Boot
approval. This is HOW the non-standard GRUB modules (procfs, archelp, play, issa1, etc.)
survive Secure Boot.

The user's OEM bypass work (Report 48) succeeded by removing GRUB modules directly.
But the certificate is still there — if the rootkit reinstalls (via Chinese Windows ISOs
or casper auto-reinstall), it will enroll this cert again.

**REMOVAL: Extract this cert, get its fingerprint, add to Secure Boot denylist (dbx).
This PERMANENTLY prevents the rootkit's modules from loading regardless of MOK status.**
